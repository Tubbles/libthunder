# Documentation index

Living documentation for libthunder. Markdown convention: one paragraph per line, let the renderer wrap.

- [vision.md](vision.md) states what we are building, why, and the legal ground rules.
- [process.md](process.md) defines how work gets done: work items, subagent usage, review gates, testing bar.
- [roadmap.md](roadmap.md) holds the phase plan and current focus.
- [plan-phase-2.md](plan-phase-2.md) breaks Phase 2 (sim core) into tracks and work items; owner-approved 2026-08-10.
- [testing-strategy.md](testing-strategy.md) describes the layered round-trip/parity testing approach against the real engine.
- [asset-manifest.md](asset-manifest.md) records the identity (sha256) and provenance of the git-ignored reference game data.
- [decisions/](decisions/) holds numbered decision records. Settled decisions are not re-litigated; a new record supersedes an old one.
- [research/](research/) holds surveys of prior art, file formats, and ecosystem, written by research agents and reviewed before commit.
- [work-items/](work-items/) holds the tickets. See process.md for lifecycle and format.
