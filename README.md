# libthunder

An open source clean-room reimplementation of the Warcraft III engine, with a companion world editor, written in [Odin](https://odin-lang.org/).

Status: pre-alpha, planning stage. See [docs/README.md](docs/README.md) for the documentation index and [docs/vision.md](docs/vision.md) for goals and constraints.

libthunder contains no Blizzard code and no Blizzard assets. Running it against the original game data requires a legally obtained copy of Warcraft III (the parity target is patch 1.29b, the last MPQ-based version). This project is not affiliated with or endorsed by Blizzard Entertainment.
